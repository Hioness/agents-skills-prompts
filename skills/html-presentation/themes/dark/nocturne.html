Style Guide / Redraft

Read it in the dark.

A nocturne take on the html-presentation design system — a dim, luminous reading surface with a quiet left-rail index. Fraunces serif for prose, hairline dividers, and a soft violet glow doing the accent work that bright color usually does.

00 Overview

Single-file HTML documents for presenting complex technical output: specs, plans, code reviews, research synthesis, prototypes. Every element earns its presence. This redraft treats the document as a calm surface to read at 1am — low contrast, generous leading, and a single glow color.

What changed in v2.0 Added .hl inline highlight — amber at 15% fill, for one load-bearing phrase per paragraph. Here it's a warm amber ember against the dark.
Scope note Prototype. Keeps dark mode but swaps the teal/Inter system for a serif + violet nocturne. Same 19 components, different mood.
Breaking change Schema migration requires a read-only window of ~2 minutes. Rollback is not automated.

08 Decisions

Numbered option headers for N-way comparisons. Genuine trade-offs use the +/− analysis grid. Concluded judgment uses the glow-bordered recommendation block.

01Horizontal hide-on-scroll nav

Nav hides on scroll-down, reveals on scroll-up. Frees vertical space on mobile.

02Persistent sidebar nav

Adds structural complexity but keeps section status visible always.

Pros · horizontal

  • Lower complexity, single column
  • Hide-on-scroll gives nav room

Cons · horizontal

  • Links vanish while reading
  • Cramped with many sections

Recommendation

Exhaust the horizontal hide-on-scroll nav first. Promote to a sidebar only when link count or persistent status demands it.
